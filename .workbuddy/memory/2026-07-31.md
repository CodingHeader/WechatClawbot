## 合规评估结论（用户问"是否合规"）

底层合规、反滥用护栏到位，但 4 个闭环待补：

1. **硬缺口**：未引用并遵守《微信ClawBot功能使用条款》——iLink（ilinkai.weixin.qq.com）是腾讯 2026-03 经 OpenClaw 框架正式开放的微信个人号 Bot API，有该条款法律背书，但设计文档/代码全程未提及，须写进 AGENTS.md/设计文档并落实受限用途。
2. **PIPL 缺失**：系统存 wechat_user_id + 对话历史 + 消息内容（个人信息），缺隐私告知/授权、数据最小化、留存期限、删除权。
3. **场景边界未界定**：iLink 当前偏"个人使用/私聊"；奖励一颗麻籽 若批量推营销通知可能超条款范围，须确认用户主动扫码绑定 + opt-in 通知。
4. **安全默认值弱**：AUTH_TOKEN 默认 change me、无限流、无审计日志；建议未配置 token 直接拒绝启动。

协议层合法（非逆向），无需改造；重点补「条款采纳 + 个保法闭环 + 场景边界」。
